## 2. Definición de objetivos (por contexto)

### 2a. Freelance / Cliente

- [ ] **Modelo de cobro definido**: Precio cerrado por proyecto *(recomendado)* o por hora — tarifa: [monto]/hora
- [ ] **Propuesta redactada**: alcance incluido, alcance excluido, precio, plazo de entrega, forma de pago
- [ ] **Forma de pago acordada**: Anticipo del **30-50%** antes de empezar + saldo contra entrega
- [ ] **Confirmación por escrito** obtenida (correo/WhatsApp) antes de empezar
- [ ] **Cláusula de Parada de Emergencia (Kill Fee)** incluida:

> "Si el cliente suspende el proyecto, no responde requerimientos en [X] días hábiles o se desaparece, el anticipo cobrado no es reembolsable y el proyecto queda congelado hasta nuevo aviso."

### 2b. Personal / Interno

- [ ] **Objetivo definido**: ¿qué problema personal, aprendizaje o necesidad resuelve?
- [ ] **Hito funcional claro**: fecha o resultado que define "primera versión lista"
- [ ] **Recursos / tecnologías a probar**: ¿qué quiero poner a prueba en este proyecto?

### 2c. IPVG / Académico

- [ ] **Requisitos de la asignatura** identificados (rúbrica, entregables, fechas)
- [ ] **Alcance alineado** con lo evaluado (ni sobre-ingeniería, ni fuera de lo pedido)
